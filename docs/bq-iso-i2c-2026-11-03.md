## ISO1640 pin map

`U_ISO` uses the ISO1640 8-pin D pin map from TI ISO1640 datasheet Table 5-1. It has no enable pin. The orderable suffix stays OPEN. Do not switch the symbol to the 16-DW pinout.

| Pin | Name | Domain |
| --- | --- | --- |
| 1 | VCC1 | Host side. Net `HOST_3V3`. |
| 2 | SDA1 | Host side, after `SW_SDA`. |
| 3 | SCL1 | Host side, after `SW_SCL`. |
| 4 | GND1 | `CELL0`. |
| 5 | GND2 | `CELL16`. |
| 6 | SCL2 | Upper BQ bus `SCL_BQ2`. |
| 7 | SDA2 | Upper BQ bus `SDA_BQ2`. |
| 8 | VCC2 | Upper REG1, brought out as `REG1_BQ2`. |

Side 1 faces the host (80 pF max). Side 2 faces the upper BQ bus (400 pF max). Each supply has its own 100 nF to its own ground, per ISO1640 section 9.2.1 (`C201` on `HOST_3V3`/`CELL0`, `C202` on `REG1_BQ2`/`CELL16`).

**CELL0 and CELL16 are not joined.** Do not join any upper net to lower SRP or SRN. GND1 is `CELL0`. GND2 is `CELL16`.

## GPIO9 reset and switch truth table

`R203` pulls `GPIO9` up to `HOST_3V3`. Value OPEN. `GPIO9` must be high at reset because GPIO9 low selects ESP32-C3 download mode. The ESP32 driver itself is a later sheet; this pull-up has to hold the net without it.

`SW_SDA` and `SW_SCL` are the host-side disconnect. MPN is OPEN. Rise time must remain valid at 100 kHz. The switch must stay off when unpowered and must not back-power `HOST_3V3` from isolator side 1.

| GPIO9 | Switch | Upper bus at host |
| --- | --- | --- |
| high (reset default via R203) | open | Upper address 0x08 is not admitted. |
| low | closed | Upper address 0x08 is admitted only after the lower device has been verified at 0x10. |

Upper SDA and SCL pull-ups stay on the upper monitor sheet (`R120`, `R121` to `REG1_BQ2`). Side-1 pull-ups are on this sheet (`R201`, `R202` to `HOST_3V3`), value OPEN.

## ALERT_BQ2

`ALERT_BQ2` is brought onto the isolation sheet and stays on the upper side. The stub ends at an explicit no-connect. It is not tied to `CELL0`. Firmware does not consume upper ALERT. A unidirectional isolator for it stays OPEN; do not invent that part or conduct ALERT across the barrier.

Warning classes:

- 30 `isolated_pin_label`. `CELL1`–`CELL15` and `CELL17`–`CELL31` each connect to one filter resistor. The harness is not part of this increment. `ALERT_BQ2` no longer appears in this class after the isolation-sheet no-connect was regenerated.

- 3 `lib_symbol_issues`. Embedded `qfbms:BQ7695202PFB` and `qfbms:ISO1640_D8` symbols. The project symbol library table has no `qfbms` entry. The symbols are stored in the sheets.

Ignored ERC checks in this KiCad configuration, not run as failures: single global label, four-way junction, SPICE model issue, and footprint-filter mismatch.
