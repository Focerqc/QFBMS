Fresh XML verifies these actual pin chains:

- U_BQ1.21 → R27.1; R27.2 → RT1.1; RT1.2 → CELL0.
- U_BQ1.23 → R28.1; R28.2 → RT2.1; RT2.2 → CELL0.
- U_BQ1.25 → R29.1; R29.2 → RT3.1; RT3.2 → CELL0.
- U_BQ1.31 → R30.1; R30.2 → RT4.1; RT4.2 → CELL0.
- U_BQ1.28 → R31.1; R31.2 → RT5.1; RT5.2 → CELL0.

For each chain, the two resistor endpoints and return are three different nets. Each resistor-to-thermistor intermediate net contains exactly those two intended pins. There is no resistor bypass. The generator places the thermistor below its series resistor and its return below the thermistor, avoiding the former wires passing back across the resistor.

Compatibility assumption, separately from procurement: supplied C configures the internal 18 kΩ pull-up, assumes 10 kΩ beta-3380 NTCs, and subtracts 500 Ω from inferred resistance (`hw_vbms32.c`, temperature setup and `NTC_RES`). The fitted R27–R31 values and RT1–RT5 values/MPNs remain OPEN. The 500 Ω correction does not prove a fitted 500 Ω part. No external thermistor bias network was added.

## GPIO9 disposition: PENDING

The false disconnect implementation is removed. SW_SDA/SW_SCL were two-pin SPST placeholders, with no GPIO control pin. They are absent from the exported component list. No replacement device is selected. Host SDA/SCL and ISO1640 side-1 SDA/SCL are electrically separate; both sides of each gap are marked PENDING. Upper bus communication is consequently unavailable. R203 remains GPIO9-to-HOST_3V3, with value OPEN. GPIO9 reaches only R203. High=open / low=connected is a future requirement, not an implemented truth table.

R201/R202 pull up the isolator side of the missing disconnect to HOST_3V3. Lower-monitor R20/R21 pull up the host bus to lower REG1; these are presently separate rails with no defined host power implementation. R120/R121 pull up upper SDA/SCL to upper REG1. Before connecting the missing switch, reconcile the host/REG1 rail relationship and pull-ups on both switch sides, aggregate sink current and switch resistance, capacitance and rise time at 100 kHz, reset/boot bias and supply sequencing/back-powering. Select a primary-datasheet-established pinout, control polarity and powered-off isolation. An OPEN suffix alone cannot establish any of those properties.

The [TI ISO164x datasheet](https://www.ti.com/lit/ds/symlink/iso1640.pdf), Figure 5-1 and pin functions, supports the retained ISO1640B 8-D map; no enable pin exists. Its side-1 80 pF and side-2 400 pF limits and supply ranges still need an actual loading/power budget. The ISO orderable suffix remains OPEN; the 16-DW pinout is not interchangeable.

Separate firmware issue, unchanged: `hw_vbms32.c` logs an unsuccessful lower-address write around lines 507–508 but still drives GPIO9 low at line 514. A maintained adaptation must verify successful communication with lower 0x10 before admitting upper 0x08. Lisp `with-com` and other direct GPIO9 writes gate repeatedly, including CAN-related uses. The future hardware/firmware contract must preserve address state and prevent an unverified upper admission across those repeated writes. Supplied source was preserved.
